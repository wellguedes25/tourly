# PRD-08: Modo Totem Interativo (Smart Kiosk)

> **Módulo:** MOD-08  
> **Fase:** MVP  
> **Status:** Aprovado

---

## 📋 Requisitos Funcionais
1. **Layout Adaptado para Telas Grandes Touchscreen**:
   - Botões gigantes e navegação simplificada sem necessidade de teclado físico.
2. **Modo Kiosk Protegido**:
   - Bloqueio de saída da aplicação e descanso de tela animado ativado após 60s de inatividade.
3. **QR Code "Leve para o Celular"**:
   - Geração de QR Code para transferir o mapa, rota ou conversa no WhatsApp para o smartphone do turista.
