# Diretrizes de UI/UX - Tourly

> **Filosofia:** Clean, Responsivo, Touch-First e Premium.

---

## 🎨 1. Paleta de Cores Padrão

- **Azul Marinho (Primária)**: `#0F172A` (Representa mar, confiança e solidez)
- **Ciano Turquesa (Destaque)**: `#0EA5E9` (Representa águas cristalinas, frescor e tecnologia)
- **Amarelo Sol (Ação / Cupons)**: `#F59E0B` (Promoções, destaques e estrelas)
- **Fundo Claro**: `#F8FAFC`
- **Superfície / Cards**: `#FFFFFF` com sombras suaves (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1)`)

---

## 📱 2. Modos de Exibição

### PWA / Smartphone
- Design com navegação via barra inferior (Bottom Navigation).
- Botões amplos com fácil clique no polegar.
- Botão verde de ação imediata "Chamar no WhatsApp".

### Totem Touchscreen (Quiosque)
- Botões e fontes superdimensionadas para toque com os dedos em telas de 21" a 55".
- Inatividade programada: Retorna à tela inicial de descanso após 60 segundos sem toque.
- Exibição visível de QR Code para escaneamento com a câmera do celular.
